# G58 — Reading as a separate center of attention
# Filed: 2026-03-11  Status: DEFERRED (no interrupt needed)
#
# When Igor reads a book, that reading session should be tracked as a
# separate locus of attention — its own TWM entry, its own attractor weight,
# its own context thread — rather than folded into the current conversation.
#
# Rationale: reading is a sustained background activity with its own state
# (position, chapter, extraction queue). Treating it as first-class attention
# lets Igor context-switch cleanly: "I was reading Damasio" is a retrievable
# state, not a lost detail from a prior turn.
#
# Implementation sketch:
#   - open_book() pushes a TWM entry: type="reading_session", attractor weight set
#   - read_chunk() updates that TWM entry (position, chapter, last extraction)
#   - reading session survives restarts via reading_state.json (already exists)
#   - cortex search for "reading" surfaces active session in context
#
# Priority: LOW — defer until Igor is stable for a few days.
# Do not interrupt Igor for this. Review at next optimization pass.
