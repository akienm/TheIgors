## METRICS FORMULAS (from prefrontal_cortex.py)

### Valence [-1.0 → +1.0]
```
pos_words = [thank, great, excellent, perfect, yes, good, love, appreciate]
neg_words = [wrong, error, fail, bad, incorrect, frustrat, annoyed]
pos = count of pos_words in (input + response)
neg = count of neg_words in (input + response)
if pos + neg == 0: valence = 0.3  # neutral default
else: valence = clamp((pos - neg) / (pos + neg), -1.0, 1.0)
```

### Friction [0.0 → 1.0]
```
friction = 0.0
if used_api: friction += 0.25
friction += retry_count × 0.10
friction += tool_failures × 0.15
friction = min(1.0, friction)
```

### ROI [-1.0 → +1.0]
```
value = 0.5 if goal_achieved else 0.0
value += 0.3 if new_learning else 0.0
effort = 0.20 if used_api else 0.05
roi = clamp(value - effort, -1.0, 1.0)
```

## MEMORY TYPES — WHEN TO USE EACH

- **EPISODIC**: Events that happened. "User asked X → I responded Y." Low inertia (0.20).
- **PROCEDURAL**: How-to + habits. Include `trigger` in metadata. Inertia 0.30+.
- **INTERPRETIVE**: What things mean. Patterns, principles, causal understanding. Inertia 0.25.
- **EXPERIENTIAL**: Sequential felt sense of an experience. Emotional arc. Inertia 0.20.
- **FACTUAL**: Objective information. "X is Y." Inertia 0.25.

Apply PROC1-3 before storing any memory: full subject-nouns, who/what/when/why, written for cold future-Igor.
