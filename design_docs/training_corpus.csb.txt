# Training Corpus — WO#138 / D038
# Word graph enrichment via staged text ingestion
# Status: implemented 2026-03-08

## Overview

The training corpus system enriches Igor's word graph with natural language
co-occurrence patterns from books (Gutenberg, local files). The word graph
previously learned only from habit triggers and narratives; training broadens
its vocabulary and bigram patterns for better habit scoring and prediction.

## Storage Design

Staged area:  ~/.TheIgors/training_corpus/
  index.json          — registry: {book_id: metadata}
  {book_id}.txt       — raw text (deleted after training)

Local source: ~/TheIgorsProject/  (env: IGOR_TRAINING_SOURCE_DIR)
  Akien's writings, notes, and reading materials.
  Scanned by scan_local_training_source() tool.

URL lists:    ~/TheIgorsProject/akien/Readings/gutenberg.org_top_100_vocabulary_expanding_books.txt
  One URL per line; loaded by load_gutenberg_list() tool.

Book ID: first 10 chars of SHA-256 of URL or local path (stable across renames).

## Status Lifecycle

  pending → in_progress → complete → (evicted)

  pending    : fetched, not yet trained
  in_progress: training started, cursor saved (resumable after restart)
  complete   : all paragraphs indexed, ready for eviction

## Eviction Policy

Eviction triggered:
  1. Before each new fetch, if disk free < IGOR_DISK_WARN_GB (default 1.0 GB)
  2. After each training run, if disk free < threshold
  3. Manually via evict_training_corpus() tool

Priority order (delete first → last):
  1. complete    — training done, no value in keeping
  2. in_progress — checkpoint cursor first, can re-fetch and resume
  3. pending     — never trained, cheapest to re-fetch

## Training Mechanics

Split: text.split("\n\n") → paragraphs >= 60 chars
Cap:   MAX_PARAS_PER_BOOK (default 800, env IGOR_TRAINING_MAX_PARAS)
       Caps growth of word_graph.json; evenly distributed across book.

Index call: word_graph.index(f"corpus_{book_id}_{i:05d}", paragraph, weight=1.0)

These corpus doc_ids do NOT pollute habit scoring:
  score(input, doc_ids) only evaluates the provided doc_ids (habit IDs).
  Corpus doc_ids simply won't appear in habit lists — they're filtered out.
  Co-occurrence graph (_cooccur) is enriched, improving predict_next().

IDF recalculated after each training run.
Word graph saved to ~/.TheIgors/word_graph.json after each book.
Changes take effect on next Igor restart (graph loaded from cache at boot).

## Resumability

para_cursor in index.json tracks paragraphs processed per book.
On restart + re-train, training resumes from cursor.
Text file must still exist (re-fetch if evicted).

## Tools (Igor-callable)

  fetch_training_text(url, title, source)   — download one book
  load_gutenberg_list(list_file)            — queue Akien's top-100 list
  scan_local_training_source()              — register ~/TheIgorsProject .txts
  train_word_graph(book_id)                 — train one book (or next pending)
  train_all_pending()                       — train all pending/in-progress
  list_training_corpus()                    — status report
  evict_training_corpus()                   — manual eviction

## Env Vars

  IGOR_TRAINING_SOURCE_DIR   — local scan root (default ~/TheIgorsProject)
  IGOR_TRAINING_MAX_PARAS    — max paragraphs per book (default 800)
  IGOR_DISK_WARN_GB          — eviction threshold (default 1.0, shared with disk monitor)
  IGOR_DISK_CRITICAL_GB      — fetch abort threshold (default 0.2)
