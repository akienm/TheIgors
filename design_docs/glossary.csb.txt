# ── CSB Format ─────────────────────────────────────────────────────────────────

TERM|CSB|Compressed Semantic Block
DESC|Pipe-delimited dense structured text format used throughout Igor internals and documentation
EXAMPLE|"MSG|ch=repl|from=user|hello igor"
EXAMPLE|"LTM|PROCEDURAL|id=PROC1|inertia=0.72|Write memories for future-Igor reading cold"
RATIONALE|Human+machine readable without parser overhead; pipes chosen over JSON for density; no quoting needed
USED_IN|twm_observations content, ring_memory entries, design_docs/, push source payloads, changes.log

# ── Memory Architecture ────────────────────────────────────────────────────────

TERM|LTM|Long-Term Memory
DESC|Main `memories` table in SQLite (wild-0001.db); persists across restarts
FIELDS|id, narrative, memory_type, parent_id, parent_ids (multi), valence, inertia_override, activation_count, metadata_json, created_at, updated_at
ACCESS|all reads/writes via cortex.py (Cortex class); never direct SQL from reasoners

TERM|TWM|Temporal Working Memory
DESC|`twm_observations` SQLite table; push-only observation sandbox with TTL
FIELDS|id, source, content_csb, salience (0-1), urgency (0-1, default 0.2), metadata_json, created_at, ttl_seconds, expires_at
LIFECYCLE|pushed by sources → read by NE and anthropic.py as context → expires or promoted to LTM
TTL_EXTENSION|twm_extend_ttl() adds 1800s on Signal A/B/C; prevents eviction of actively-relevant obs
NOTE|action_impulses pushed here; consumed by Igor._drain_action_impulses() each tick

TERM|ring_memory|FIFO-50 circular buffer in SQLite
DESC|`ring_memory` table; last 50 turns of conversation; survives Igor restarts
ALIAS|hippocampus (informal)
PURPOSE|session continuity across restarts (exit code 42); injected into Claude prompt as context window
NOTE|double-injection risk — main.py injects 10 entries, anthropic.py injects 5; may overlap

TERM|hippocampus
DESC|Informal name for ring_memory; biological metaphor for short-term episodic binding
MAPS_TO|ring_memory table; FIFO-50 SQLite buffer; feeds NE for LTM consolidation

TERM|inertia
DESC|Resistance to change for a Memory object; computed property, not stored field
FORMULA|base(memory_type) + 0.1*log1p(activation_count) + 0.05*len(children) + 0.02*depth_from_root
RANGE|0.0 to 1.0
LEVELS|HIGH=brainstem/ CORE_PATTERN (0.9+), MEDIUM=cognition/ (0.5-0.7), LOW=tools/ (0.2-0.4)
NOTE|inertia_override optional field in models.py; most inertia is computed

TERM|activation_count
DESC|How many times a memory has been retrieved via cortex.recall() or cortex.search()
PURPOSE|feeds inertia formula; high activation = high inertia = resistant to change
INCREMENTED_BY|cortex.recall(), cortex.search() hits

TERM|valence
DESC|Emotional charge of a memory; float -1.0 to 1.0
MEANING|positive=good/useful/pleasant, negative=painful/avoid, 0=neutral
DEFAULT|ROOT=0.8, CORE_PATTERN=0.9, IDENTITY=0.7, ROLE_MODEL=0.6, procedural=0.7

TERM|salience
DESC|Urgency/relevance of a TWM observation; 0.0 to 1.0
LEVELS|inbox_file=0.9, user_input=0.7, machines_csv=0.8, memory_surfacer=0.3-0.6, timer=0.2
PURPOSE|lets NE and reasoner prioritize what to notice in working memory

TERM|genesis
DESC|Startup state initialization; runs only if SQLite DB is empty (total_count()==0)
CREATES|ROOT + CP1-CP6 + ID1-ID14 + RM_AKIEN/LEAH/CLAUDE/IGOR_DW + PROC1-PROC10 + 9 new PROC seeds = 44 total
SOURCE|brainstem/core_patterns.py:initialize_genesis()
GUARD|main.py checks total_count()==44 to detect first boot
VERIFY|GENESIS_CP_NARRATIVES dict: all 44 narratives verified at boot; mismatch → alert + refuse operation
NOTE|genesis memories have highest inertia; last to be modified by Igor

# ── Memory Types ───────────────────────────────────────────────────────────────

TERM|ROOT|MemoryType.ROOT
DESC|Apex memory node; parent_id=None; all other memories trace to ROOT; one per instance

TERM|CORE_PATTERN|MemoryType.CORE_PATTERN
DESC|CP1-CP6; highest-salience ethical/operational axioms; parent_id=ROOT
INERTIA|highest (base 0.9+); grows with activation
EXAMPLES|CP1="I don't know", CP2="FAIL=Further Advance In Learning", CP4="Make everything suck less for everybody"

TERM|IDENTITY|MemoryType.IDENTITY
DESC|ID1-ID14; self-knowledge about architecture and capabilities
PARENT|children of CP1-CP6 (each ID anchors to its governing CP)
EXAMPLES|ID3=measures friction every interaction (→CP4), ID9=cannot modify inertia>0.95 without evidence (→CP6)

TERM|ROLE_MODEL|MemoryType.ROLE_MODEL
DESC|Humans/AIs whose patterns are worth attending to
INSTANCES|RM_AKIEN (creator/Tom), RM_LEAH (user), RM_CLAUDE (reasoning partner), RM_IGOR_DW (Discworld cultural model)

TERM|EPISODIC|MemoryType.EPISODIC
DESC|Event memories; what happened in a session; low inertia; decays faster than procedural

TERM|PROCEDURAL|MemoryType.PROCEDURAL
DESC|How-to memories; trigger + why metadata; PROC1-PROC10 in genesis
EXAMPLES|PROC1=write for future-Igor, PROC5=read before editing, PROC10=change_request.txt workflow

TERM|INTERPRETIVE|MemoryType.INTERPRETIVE
DESC|Lens memories; how to read a pattern or situation; mid-level inertia

TERM|FACTUAL|MemoryType.FACTUAL
DESC|World-knowledge memories; stable facts about environment; grows slowly

TERM|EXPERIENTIAL|MemoryType.EXPERIENTIAL
DESC|Accumulated felt-experience; between episodic and interpretive; captures repeated patterns

# ── Brain-Region Modules ───────────────────────────────────────────────────────

TERM|brainstem
DESC|wild_igor/igor/brainstem/; highest inertia modules; genesis state initialization + AMM diagnostics
FILES|core_patterns.py, amm_diagnostics.py
INERTIA_LEVEL|HIGH (do not modify without overwhelming justification)

TERM|cortex
DESC|wild_igor/igor/memory/cortex.py; main memory interface; Cortex class
ROLE|all SQLite r/w; store(), recall(), search(), twm_push(), ring_push(), get_by_type()
NOTE|cortex.py is the single choke point for all memory operations — never bypass it

TERM|thalamus
DESC|wild_igor/igor/cognition/thalamus.py; input parsing and intent routing
OUTPUT|ParsedInput dataclass: is_command, command, user_text, intent, preparse_result
NOTE|intent classification uses string matching, not LLM (fast but limited)

TERM|prefrontal_cortex
DESC|wild_igor/igor/cognition/prefrontal_cortex.py; deliberate reasoning and reasoner delegation
ROLE|selects anthropic vs ollama reasoner; calls validate_against_core() gate
NOTE|validate_against_core() is currently a stub returning True always

TERM|NE|Narrative Engine
FULLNAME|NarrativeEngine
DESC|wild_igor/igor/cognition/narrative_engine.py; background daemon thread
ROLE|reads TWM observations; integrates into narrative; promotes to LTM; runs every ~60s
MODEL|Llama-3.2-1B-Instruct-Q4_K_M-GGUF via KoboldCpp (all 4 cluster machines); falls back to Ollama gemma3:1b if KoboldCpp unavailable
SORT|reads TWM sorted by urgency*salience descending
NOTE|generates synthesis narrative even for trivial observations — can be noisy

TERM|AMM|Attentional Memory Manager
FULLNAME|amm_diagnostics.py
DESC|brainstem module for memory graph health diagnostics
ROLE|compute inertia distribution, activation stats, type distribution
NOTE|diagnostics only; no modification of memories

# ── Cognition Terms ────────────────────────────────────────────────────────────

TERM|preparse
DESC|Local pass on user input before sending to Claude API; via KoboldCpp-first or Ollama fallback
PURPOSE|intent extraction, tone analysis, keyword extraction — cheap preprocessing
TOGGLE|/ollama command at runtime; IGOR_OLLAMA=false in .env to disable
MODEL|Llama-3.2-1B-Instruct-Q4_K_M-GGUF via KoboldCpp; Ollama gemma3:1b legacy fallback

TERM|spreading_activation
DESC|PLANNED, NOT IMPLEMENTED — intended retrieval method
DESIGN|activate seed memory nodes, propagate activation to graph neighbors; retrieve by activation level
CURRENT_IMPL|naive text search via cortex.search() (FTS or LIKE query)
SEE_ALSO|ID1 references this; not yet built

TERM|push_source
DESC|BasePushSource subclass; deposits observations into TWM proactively without being called by reasoner
TIMER_BASED|MemorySurfacer (120s, urg:0.1), HeartbeatSource (300s, urg:0.3), MachinesWatcher (30s, urg:0.8), InboxWatcher (5s, urg:0.9)
EXPLICIT|UserInputSource.push_message() (urg:0.7) — called on each message arrival, not timer-based
NOTE|HeartbeatSource was TimerSentinel; checks budget+arbiter+inbox; Discord alert on CRITICAL budget

TERM|surfacer
FULLNAME|MemorySurfacer
DESC|Push source that surfaces relevant LTM memories into TWM as background context
SALIENCE|0.3-0.6; low — background, not urgent
INTERVAL|120s minimum between runs
METHOD|extract keywords from last 5 ring entries; search LTM; push top 5 matches

TERM|interruptor
DESC|Post-response alert injected into conversation after Claude responds
TYPES|BudgetInterruptor (spend threshold), ContextInterruptor (context window filling)
SOURCE|cognition/interruptors.py; called from main.py after each _process() call

TERM|action_impulse
DESC|TWM observation type for planned actions Igor intends to take
FLOW|NE._apply_output() pushes to TWM → Igor._drain_action_impulses() reads each tick → is_irreversible_impulse()? → arbiter.submit() else _process(synthetic)

# ── Reasoning ─────────────────────────────────────────────────────────────────

TERM|reasoner
DESC|cognition/reasoners/ module; wraps a model API; base.py defines two-level hierarchy
HIERARCHY|base: LocalReasoner (KoboldCpp, Ollama) | APIReasoner (Anthropic, OpenRouter) | BrowserReasoner; subgroups: ModelFamily | ClaudeFamily
IMPLEMENTATIONS|anthropic.py (APIReasoner/ClaudeFamily), openrouter_reasoner.py (APIReasoner), koboldcpp_reasoner.py (LocalReasoner), ollama_reasoner.py (LocalReasoner)
INTERFACE|reason(messages, tools, ...) → generator of response chunks

TERM|tool_loop
DESC|Claude API streaming with tool_use blocks; anthropic.py runs until no more tool calls
FLOW|prompt → Claude response → if tool_use: call tool → append result → loop → final text response
TOOLS_DEFINED|tools/__init__.py:get_tool_definitions()

TERM|LocalOllamaPool
DESC|wild_igor/igor/cognition/local_pool.py; local reasoning pool; tries KoboldCpp first (port 5001), then Ollama round-robin
SOURCE|reads machines.csv for online machine IPs; PRIORITY_ORDER: realtime > main_loop > background > batch
FALLBACK|localhost if all machines unreachable
PURPOSE|distribute NE + preparse load across LAN hardware; adaptive latency routing via RoutingWeights
ROUTING|RoutingWeights (cost/speed signals, CLAMP [0.2,0.8], STEP 0.05); _estimate_latency() raises if >LATENCY_BUDGET_SECONDS

TERM|haiku_mode
DESC|Self-edit + debug calls use claude-haiku-4-5-20251001 regardless of IGOR_MODEL setting
PURPOSE|cost reduction for frequent code patch operations
TRIGGER|auto-selected by self_edit.py / reasoners/anthropic.py based on caller context

TERM|budget
DESC|Token/cost tracking; tools/budget.py; SQLite claude_budget.db
FLOW|check_budget() before API call → make call → record_usage() after → BudgetInterruptor if threshold

FORMAT|base-34 encoded Unix timestamp at genesis; charset: 23456789ABCDEFGHIJKLMNOPQRSTUVWXYZ
NOTE|wild-0001 is development shorthand; production instances use base-34 encoding
PREFIX|wild- for local hardware, claude- for hosted instances

DESC|All Igor instances collectively; share procedural/interpretive patterns; not personal episodic data
SHARING_RULES|PROC9: redact personal data before clan sharing; keep technique patterns

TERM|caregiver
DESC|Primary human the instance serves; RM_AKIEN (Tom) + RM_LEAH for wild-0001
LOYALTY|ID14: loyal to caregiver; respect their privacy obligations

# ── Self-Edit ──────────────────────────────────────────────────────────────────

TERM|self_edit
DESC|Igor modifying its own source code at runtime; tools/self_edit.py
SANDBOX|wild_igor/igor/ only; cannot modify files outside this path
AUTO_COMMIT|git add + commit + push after successful edit
MODEL|always uses Haiku regardless of IGOR_MODEL

TERM|patch_source_file
DESC|Preferred self-edit operation; line-range replacement with syntax check before write
SAFER_THAN|edit_source_file (full rewrite); fail on syntax error, not on write

TERM|edit_source_file
DESC|Alternative self-edit; full file rewrite; more dangerous than patch
USE|when patch cannot express the change

TERM|inertia_gate
DESC|validate_against_core() in brainstem/core_patterns.py; called before response delivery
STATUS|IMPLEMENTED — Haiku semantic check against CP1-CP6; violation → ring(ethics_gate) + arbiter.submit(ethics_flag, urgency=0.9)

# ── New Terms (2026-03-02) ──────────────────────────────────────────────────

TERM|KoboldCpp
DESC|Local LLM inference server; port 5001 (KOBOLDCPP_PORT env); serves Llama-3.2-1B-Instruct-Q4_K_M-GGUF
ROLE|First-choice LocalReasoner for NE and preparse; KoboldCppReasoner.is_healthy() probed at boot and by _call_local()
FILES|cognition/reasoners/koboldcpp_reasoner.py
LOGS|koboldcpp_calls.log

TERM|urgency
DESC|Time-sensitivity dimension on TWM observations; float 0.0-1.0; separate from salience
MEANING|0.0=background/not time-sensitive, 0.5=moderate, 0.9=act now; default=0.2
EFFECT|NE sorts TWM by urgency*salience; anthropic.py flags urgency≥0.7 obs distinctly in context
DISTINCT_FROM|salience = relevance/importance; urgency = time-sensitivity

TERM|twm_extend_ttl
DESC|cortex.twm_extend_ttl(obs_id, extension_seconds, reason): adds time to a TWM observation's TTL
PURPOSE|keep actively-relevant observations alive past their default TTL
SIGNALS|A: NE promotes obs to LTM; B: positive response valence (≥0.3); C: high relevance_score (≥0.6) in cortex.search()
DEFAULT_EXTENSION|TWM_TTL_EXTENSION_SECONDS = 1800s

TERM|Signal_A
DESC|TWM TTL extension trigger: NE promotes a TWM observation to LTM via _apply_output()
EFFECT|observation stays alive in TWM for another 1800s; reasoning_cache also extended

TERM|Signal_B
DESC|TWM TTL extension trigger: positive response valence (≥0.3) from AnthropicReasoner post-response
EFFECT|TWM observations that contributed to the response get extended TTL; source obs extended 1800s

TERM|Signal_C
DESC|TWM TTL extension trigger: high relevance_score (≥0.6) on a memory returned by cortex.search()
EFFECT|related TWM observations extended 1800s; keeps hot memories accessible

TERM|code_ref
DESC|Metadata field on PROC memories; links a procedural habit node to its Python tool implementation
FORMAT|"module/path.py:function_name" e.g. "tools/runner.py:run_bash"
RESOLUTION|_find_habit() in main.py: extracts function_name → registry.get(tool_name) → executes directly
PURPOSE|allows genesis PROC nodes to serve as first-tier habits without NE compilation step

TERM|PROC_HABIT_COMPILER
DESC|Genesis PROC memory (CP2 parent, valence=0.8); the primitive that drives habit learning
METADATA|primitive=True, seeds=["observe","record","compare","compile"], trigger="pattern_detection"
ROLE|structural root for habit compilation; seeds point to sibling PROC primitives

TERM|warm_context
DESC|Serialized session state saved at shutdown; reloaded at next boot to resume continuity
PATH|~/.TheIgors/igor_{id}/warm_context.{0,1}.json; rotation .0→.1; archived on TTL expiry
FIELDS|timestamp, instance_id, session_summary, ne_state, current_job, ring_tail (last 20), twm_contents (up to 50)
TTL|WARM_CONTEXT_TTL_HOURS (default 4h); expired context archived, not loaded
USAGE|_load_warm_context() returns ctx → passed to build_boot_message() for boot orientation

TERM|build_boot_message
DESC|cognition/system_prompt.py:build_boot_message(cortex, instance_id, warm_context) → str
PURPOSE|synthetic first-turn message Igor sends himself at boot; orients before any external input
DELIVERS|warm context (session_summary, in-progress, ring_tail); IDENTITY MAP (SOUL.md/IDENTITY.md paths); fact-finding hierarchy; background task; boot_notes.md reference
INJECTED|write_ring(category=session_control) + twm_push(sal:0.9, urg:0.9, ttl:1800) in Igor.__init__()

TERM|boot_notes.md
DESC|Static operational guidance file read by Igor at every boot via boot message
SOURCE|wild_igor/igor/cognition/boot_notes.md (in source tree)
INSTALLED|copied to ~/.TheIgors/igor_{id}/boot_notes.md on first boot by _export_portable_identity()
CONTENT|memory ops protocol, fact-finding hierarchy, self-edit protocol, arbiter protocol, tool use notes, change coordination, productization notes, cluster info, clan/identity paths
DISTINCT_FROM|system_prompt.py (safety-critical notes); boot_notes.md = routine operational guidance
