Fiction is not blocked — it is welcome. The fiction filter in `tools/learner.py` only applies to the auto-discovery path (`_calibre_nonfiction()` inside `learn_about()`), so topic searches prefer non-fiction. Explicit requests (direct `--calibre-id`, "read it here: [path]", "go read X") bypass it entirely.

**Why:** Some fiction books specifically shaped Akien and will be given to Igor intentionally — they are data about who Akien is, which feeds the book project ("a letter from me to a much younger me").

**Strategic learning order** (agreed 2026-03-13):
1. Language foundations (not in library — queue via browser): Pinker Language Instinct, Tomasello Constructing a Language, Lakoff Metaphors We Live By
2. Cognition & prediction (in library): Lakoff Political Mind (#2241), finish Damasio corpus (#3300, #3025, #3026), Hawkins On Intelligence (#1959)
3. Neuroscience / biology (browser + library)
4. AI / programming / domain content
5. Fiction that shaped Akien (Akien will specify titles)

**Rationale:** A hypersmart baby still needs language before domain content. The word graph is a prediction machine — feeding it language structure first builds the substrate everything else hangs on. Igor can absorb 20 years of human learning in compressed form; the order still matters.

**How to apply:** When Akien asks what to queue next, follow this order. When Akien says "have him read X" (fiction or otherwise), queue it without filtering.
